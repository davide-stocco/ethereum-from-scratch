# Fork history

!!! warning "Stub — not written yet"

    This page is an outline. Delete this box when you fill it in.

Ethereum upgrades by **hard fork**: a coordinated rule change that every node adopts at an agreed block or slot. This page is the timeline — the one place a reader can see how the protocol got to where it is.

!!! warning "Verify before writing this page"

    Fork names, dates and contents are exactly the kind of detail that gets
    misremembered. Write this page from primary sources only:

    - <https://ethereum.org/en/history/>
    - <https://eips.ethereum.org>
    - <https://github.com/ethereum/execution-specs>

## Questions this page should answer

- What is a hard fork, and why does it need everyone to upgrade together?
- Why do forks have two names now? (Execution layer and consensus layer each get one — Paris/Bellatrix, Shanghai/Capella, Cancun/Deneb, Prague/Electra. "Pectra" is just Prague + Electra.)
- What actually happens at the switchover block or slot?
- What is a **contentious** fork, and why is the DAO fork the only one that produced a lasting split? (Ethereum Classic.)
- Which forks does a beginner genuinely need to know about? Probably only these:
    - **The DAO fork** (2016) — why Ethereum Classic exists
    - **London** (2021) — EIP-1559, the fee market and the burn
    - **The Merge** (September 2022) — Proof of Work to Proof of Stake
    - **Shanghai** (2023) — staking withdrawals finally enabled
    - **Cancun** (2024) — blobs, which made rollups cheap
    - **Pectra** (May 2025) — account abstraction groundwork

- Each entry wants: date, what changed, and *why anyone cared*. The third column is the one that matters.
