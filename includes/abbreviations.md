*[ABI]: Application Binary Interface — the convention for encoding contract calls
*[EOA]: Externally Owned Account — an account controlled by a private key
*[EOAs]: Externally Owned Accounts — accounts controlled by private keys
*[EVM]: Ethereum Virtual Machine — the machine that executes contract code
*[EIP]: Ethereum Improvement Proposal — a numbered proposal for changing Ethereum
*[EIPs]: Ethereum Improvement Proposals — numbered proposals for changing Ethereum
*[RLP]: Recursive Length Prefix — Ethereum's encoding for structured data
*[UTXO]: Unspent Transaction Output — Bitcoin's coin-based state model
*[UTXOs]: Unspent Transaction Outputs — Bitcoin's coin-based state model
*[PoS]: Proof of Stake — the consensus mechanism Ethereum uses since 2022
*[PoW]: Proof of Work — mining, the mechanism Ethereum used before 2022
*[ECDSA]: Elliptic Curve Digital Signature Algorithm
*[secp256k1]: The elliptic curve Ethereum and Bitcoin use for signatures

*[canonical]: Agreed on and permanently recorded by the network — as opposed to merely having existed
*[deterministic]: The same inputs always produce the same result, for everyone
*[determinism]: The property that the same inputs always produce the same result, for everyone
*[oracle]: A service that reports off-chain facts to a contract — and a point of trust whenever you need one
*[oracles]: Services that report off-chain facts to contracts — and points of trust whenever you need them
*[nonce]: A per-account counter of transactions already sent; prevents replay and forces ordering
*[state root]: A single 32-byte fingerprint committing to the entire state, carried in each block header
*[receipt]: The record of what a transaction did — gas used, logs emitted, success or failure
*[receipts]: The records of what transactions did — gas used, logs emitted, success or failure
*[Turing-complete]: Able to express any computation, loops included
*[Beacon Chain]: The Proof of Stake chain that ran separately from December 2020, holding no accounts
*[Keccak-256]: Ethereum's hash function — any input in, 32 bytes out
*[Script]: Bitcoin's scripting language — deliberately stateless and limited
*[hard fork]: A coordinated rule change that every node adopts at an agreed point
*[Yellow Paper]: Ethereum's formal specification, by Gavin Wood
