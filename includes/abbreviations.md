*[ABI]: Application Binary Interface — the convention for encoding contract calls
*[EOA]: Externally Owned Account — an account controlled by a private key
*[EOAs]: Externally Owned Accounts — accounts controlled by private keys
*[EVM]: Ethereum Virtual Machine — the machine that executes contract code
*[EIP]: Ethereum Improvement Proposal — a numbered proposal for changing Ethereum
*[EIPs]: Ethereum Improvement Proposals — numbered proposals for changing Ethereum
*[RLP]: Recursive Length Prefix — Ethereum's encoding for structured data
*[UTXO]: Unspent Transaction Output — Bitcoin's coin-based state model
*[UTXOs]: Unspent Transaction Outputs — Bitcoin's coin-based state model
*[PoS]: Proof of Stake — the consensus mechanism Ethereum uses since 2022
*[PoW]: Proof of Work — mining, the mechanism Ethereum used before 2022
*[ECDSA]: Elliptic Curve Digital Signature Algorithm
*[secp256k1]: The elliptic curve Ethereum and Bitcoin use for signatures
*[gwei]: One billion wei, the unit fees are normally quoted in
*[wei]: The smallest unit of ether; 10^18 wei make one ether
